Types of relationships
One-to-One Relationship (1:1)
Each record in the first table matches exactly one record in the second table, and vice versa 🎯
Think of it like this:

Like a person and their passport - each person has exactly one passport, and each passport belongs to exactly one person! 🛂

One-to-Many Relationship (1:N)
One record in the first table can relate to multiple records in the second table, but each record in the second table relates to only one record in the first table 📚
Think of it like this:

Like a teacher and their students - one teacher can have many students, but each student has only one teacher (in this example)! 👩‍🏫

Many-to-Many Relationship (M:N)
Multiple records in the first table can relate to multiple records in the second table 🔄
Think of it like this:

Like students and courses - a student can take multiple courses, and each course can have multiple students! 📚
